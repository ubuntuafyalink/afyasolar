# Afya Solar — Design System (Master)

> When building a page, check `design-system/afya-solar/pages/[page].md` first; if it exists it overrides this file.
> Otherwise follow the rules below. This file was generated by ui-ux-pro-max then hand-tuned to Afya Solar's real
> green identity and tokens ([src/styles/globals.css](../../src/styles/globals.css)).

**Product:** Healthcare-solar platform — admin/facility/technician/management dashboards + public/auth.
**Feel:** Premium, calm, clean, international. Clutter-free; important information prioritized. **Light mode only.**

---

## Color — green identity (do NOT drift off green)

Tokens live in `@theme inline` / `:root` of [globals.css](../../src/styles/globals.css) as **oklch**. Approx hex for reference:

| Role | Token | oklch | ~hex |
|------|-------|-------|------|
| Primary (brand green) | `--primary` | `oklch(0.60 0.17 145)` | `#16A34A` |
| Primary foreground | `--primary-foreground` | `oklch(0.99 0 0)` | `#FFFFFF` |
| Success | `--success` | = primary green | `#16A34A` |
| Warning | `--warning` | `oklch(0.78 0.16 85)` | `#E0A423` |
| Solar (amber accent) | `--solar` | `oklch(0.78 0.13 85)` | `#E4B24D` |
| Destructive | `--destructive` | `oklch(0.55 0.22 25)` | `#DC4B3E` |
| Background | `--background` | `oklch(1 0 0)` | `#FFFFFF` |
| Surface (raised card tint) | `--surface` | `oklch(0.985 0.006 145)` | `#FAFCFA` |
| Foreground | `--foreground` | `oklch(0.18 0.02 150)` | `#16241C` |
| Muted foreground | `--muted-foreground` | `oklch(0.45 0.02 150)` | `#5B6B62` |
| Border | `--border` | `oklch(0.92 0.01 145)` | `#E6EBE7` |

**Rules:** green is the single brand hue. Amber `--solar`/`--warning` is the *only* accent, used sparingly for
energy/solar and caution. Status = colour **+ icon + text**, never colour alone (colour-blind safe). Charts stay within
green→teal→amber; red only for negative/critical.

## Typography
- **Body + headings:** PT Serif (via `--font-sans`). **Numerals/amounts:** JetBrains Mono (unicode-range digit swap).
- **Type scale:** 12 · 14 · 16 · 18 · 24 · 32 (`text-xs`…`text-3xl`). Body ≥16px on mobile; line-height 1.5–1.75.
- Headings: `font-semibold`/`font-bold` (PT Serif ships 400/700 — 500/600 synthesize).

## Spacing (4/8 rhythm)
`--space-xs 4 · sm 8 · md 16 · lg 24 · xl 32 · 2xl 48 · 3xl 64`. Card padding `p-5`/`p-6`; section gaps `space-y-6`/`8`;
grid gaps `gap-3`/`4`. Container `max-w-7xl mx-auto`.

## Elevation (tinted, not pure black — see globals.css `--shadow-*`)
`--shadow-xs` hairline · `--shadow-sm` resting card · `--shadow-md` hover/raised · `--shadow-lg` popover/dropdown ·
`--shadow-xl` dialog/featured. Shadows carry a faint green-neutral tint for a premium feel. Radius: `--radius .5rem`
(`sm/md/lg/xl` derived); cards `rounded-xl`, controls `rounded-md`, pills `rounded-full`.

## Motion (framer-motion, under LazyMotion + reduced-motion)
Transform/opacity only, 150–300ms, ease-out. Primitives in [src/components/motion/](../../src/components/motion/):
`fadeInUp`, `scaleIn`, `staggerContainer`, `hoverLift`, `pressable`, `pageTransition`. Scroll reveals use
`whileInView` + `viewport={{ once:true }}`. Never animate an LCP element's layout. Everything respects
`prefers-reduced-motion` (global `MotionConfig reducedMotion="user"`).

## Components (use shadcn compound primitives in [src/components/ui/](../../src/components/ui/))
- **Button** — variants default/outline/secondary/ghost/destructive/link; press micro-interaction; visible focus ring;
  `loading` disables + spinner.
- **Card** — `rounded-xl`, `--shadow-sm` resting; interactive cards get `hoverLift` (+`--shadow-md`, translateY -2px)
  and `cursor-pointer`.
- **StatCard** — KPI tile: muted label · large value (mono numerals) · meta/delta · tinted icon chip. Accent bar
  optional (`showAccent`).
- **Badge/pill** — variants incl. success/warning/solar; `rounded-md` (pills `rounded-full`).
- **Input/Select** — 16px text, `rounded-md`, visible focus ring (`ring-ring/50 ring-[3px]`).
- **Dialog** — overlay blur, `rounded-xl`, `--shadow-xl`, AnimatePresence in/out.
- **EmptyState / Skeleton** — every async surface has both.

## Anti-patterns
❌ Off-brand hues (blue/purple as primary) ❌ emojis as icons (use lucide) ❌ colour-only status ❌ layout-shifting
hovers ❌ `<4.5:1` contrast ❌ invisible focus ❌ instant state changes ❌ raw hex instead of tokens ❌ clutter /
low-priority info competing with key metrics.

## Pre-delivery checklist
- [ ] Tokens (not raw hex); green identity intact
- [ ] lucide icons only; icon-only buttons have `aria-label`
- [ ] `cursor-pointer` + hover feedback on interactive elements
- [ ] Focus states visible; keyboard order matches visual
- [ ] Contrast ≥4.5:1 on green surfaces
- [ ] `prefers-reduced-motion` respected; motion ≤300ms transform/opacity
- [ ] Responsive 375 / 768 / 1024 / 1440; no horizontal scroll
- [ ] Loading (skeleton) + empty states present
- [ ] EN/SW i18n preserved
